# Runbook: incident

**Status: not yet written.** Required by Phase 5's exit criteria, which demand that each runbook
exists *and has been rehearsed once*. A runbook that has never been executed is fiction.

Must contain:

1. Preconditions and who can perform this.
2. Exact commands, copy-pasteable, with expected output at each step.
3. How to verify it worked.
4. How to roll back.
5. Date of last rehearsal.
